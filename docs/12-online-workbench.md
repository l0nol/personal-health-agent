## 2. 口径沿用（不是"差不多"，是同一条规则）

- **只统计已确认**：记录「状态」= 待确认的，不进趋势、不进参照范围；手工录入默认「已确认」。
- **参照范围 = 个人基线**：28 天窗口、≥14 天有效、中位数 ± 2.5×MAD；MAD=0 用 IQR/1.349 兜底；仍为 0 或样本不足 → 显示「数据不足」，**不拿默认值冒充**。
- **区间端点不算均值**：HRV / 血氧的上限、下限标 `rangeBound`，趋势页不给均值与中位数，也不画中线。
- **缺失不补 0**：缺失日留空断线；睡眠图缺失画空心柱。
- **建议优先级同 0.1.3**：明显不适 → 资料不足 → 休息 → 轻松活动 → 常规训练；正文避开「高强度/力竭/减脂/燃脂/补偿」等禁用词（自检脚本会扫）。
- **睡眠参考值 420 分钟**标明来源（成人 7–9 小时下沿，未按年龄调整），不写成"你的目标"。

## 3. 数据流

```
页面（在线）──读写──> 资料库三张表 ──> 每次写入后重拉全量（分页、游标保护）──> 重算基线/建议 ──> 重渲染
                              └──「导出 JSON」按钮：随时下载本地快照
```

- 读取：每表分页 200 条 / 次，`startCursor` + `hasMore` + 守卫上限 100 页，不会只读第一页就当真。
- 写入：`addRecord` / `updateRecord`（今日状态同日覆盖）/ `deleteRecord`（二次确认）。
- 降级：平台 SDK 拿不到时显示「离线预览」，页面结构与示例文案照常渲染，不白屏。

## 5. 质量门的 2 条声明（如实交代）

- **PQ001「括号未配平」**：扫描器把脚本里的除法表达式（如 `m / 60`）误判成正则字面量。`node --check` 与冒烟测试都通过，判定为误报。
- **PQ005「innerHTML 拼接未转义」**：所有进入 `innerHTML` 的 database / 用户文本在拼接前都过 `escapeHtml()`，数字由 `formatValue()` 产出。未改成 `textContent` 是因为整页采用字符串模板渲染，改动面大于收益。

## 6. 维护

- **改页面**：编辑态链接里改，或本地改完用 `import_html.py --node-block-id yqYfuXLN1g5lE2JzcDhZZf` 覆盖并重新发布（链接不变）。
- **加指标**：先给「健康指标记录」表的 `指标` 字段加选项，再在页面 `CATALOG` 里加一条（名称必须逐字一致，否则取不到单位与精度）。
- **清示例数据**：页面顶部「清空示例数据」，只删备注为「示例数据」的行。
- **备份**：页面右上「导出 JSON」；云端数据本身也在资料库里，可随时在表里看。
