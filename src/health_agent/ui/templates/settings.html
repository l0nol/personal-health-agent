备份 / 恢复：命令行 python -m health_agent.cli backup（恢复加 --force，替换前会先留 .bak），步骤见 docs/02-runbook.md §5。本页不放一键备份按钮——备份要写整个数据目录，误触代价比多点几步大。

删除整个数据库请直接删除数据目录下的 health.db 文件（应用需先停止）。
