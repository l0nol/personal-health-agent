# 平板端手动验证清单（T10 版）

- 适用设备：联想 Yoga Pad Pro 12.7（Android，联想浏览器 / Chrome）
- 目的：让服务在局域网内可访问，然后由你手动确认版式、触控与新页面
- 当前状态：**未在真机验证**。本清单只提供可复现步骤，不代表已经通过

> 安全前提：本版本**没有 HTTPS**，只有单密码鉴权。只在自己信任的家庭 Wi-Fi 下开启；
> 不要在公共 Wi-Fi、公司开放网络或公网暴露。

---

## 一、电脑端：三步把服务开起来

### 1. 生成密码（只做一次）

```bash
cd personal-health-agent
source .venv/bin/activate            # Windows: .venv\Scripts\activate
health-agent passwd
```

把输出的这一行原样写进项目根目录的 `.env`：

```ini
HEALTH_AGENT_PASSWORD_HASH=pbkdf2_sha256$...
```

### 2. 允许局域网访问并监听所有网卡

`.env` 里同时要有这两行（缺一不可）：

```ini
HEALTH_AGENT_LAN=1
HEALTH_AGENT_HOST=0.0.0.0
```

- 只设 `LAN=1` 不设 `HOST`，服务仍然只听 `127.0.0.1`，平板连不上；
- 只设 `HOST=0.0.0.0` 不设密码，程序会拒绝启动（这是刻意的）。

### 3. 找到电脑的局域网 IP，并放行端口

```bash
# Linux
hostname -I
sudo ufw allow 8000/tcp        # 若启用了 ufw

# macOS
ipconfig getifaddr en0

# Windows（PowerShell / CMD）
ipconfig
netsh advfirewall firewall add rule name="health-agent" dir=in action=allow protocol=TCP localport=8000
```

记下形如 `192.168.1.23` 的地址（不是 `127.0.0.1`）。

### 4. 启动

```bash
health-agent serve --port 8000
```

先在电脑上自测：

```bash
curl http://127.0.0.1:8000/healthz
# 期望：{"status":"ok"}
curl http://192.168.1.23:8000/healthz
# 期望同样是 {"status":"ok"}；这一步不通，平板一定不通
```

## 二、平板端：打开与登录

1. 平板与电脑连**同一个 Wi-Fi**（不要一个连 5G、一个连访客网络）。
2. 联想浏览器地址栏输入：`http://192.168.1.23:8000`（换成你的 IP）。
3. 出现登录页后输入第 1 步设置的密码。
4. 打开成功后，建议先把浏览器缩放设为 100%，关闭"无图/极速/省流"模式。

**打不开时的排查顺序**（按命中率排序）：

| 现象 | 先查什么 | 处理 |
|---|---|---|
| 连接超时 | 电脑本机 `curl http://<IP>:8000/healthz` 是否通 | 不通 → 检查 `HEALTH_AGENT_HOST=0.0.0.0` 与防火墙 |
| 连接被拒绝 | `netstat -ano \| findstr :8000`（Windows） | 端口没监听或被别的进程占用 |
| 一直跳登录页 | 浏览器是否禁用了 Cookie | 允许本站 Cookie；不要用无痕 + 第三方拦截 |
| 页面没有样式 | `/static/app.css` 是否 200 | 反向代理/省流模式可能拦截静态资源 |
| 打开很慢 | Wi-Fi 是否隔离（AP isolation） | 关闭路由器的"访客网络隔离" |

- 刻度是否清楚、中心助手图标是否好点；

## 四、记录与回传

把上表结果（✓ / ✗ / 备注）连同下面三项一起回传：

1. 平板型号与浏览器内核版本（联想浏览器 → 设置 → 关于）；
2. 横屏、竖屏首页各一张截图；
3. 出错时的页面截图 + 电脑终端最后 20 行日志。

有了这三项，才能判断是 CSS 断点问题、Cookie 问题还是网络问题。

## 五、这次**没有**验证的项（不要当成已通过）

- 真实华为健康数据导入后的版式（当前演示库是合成数据）；
- HTTPS / 证书（未实现）；
- 屏幕阅读器（TalkBack）朗读顺序；
- 多用户同时访问；
- 长时间后台后的会话保持（Cookie 为会话级）；
- 平板上的文件选择器与 CSV 下载路径。
