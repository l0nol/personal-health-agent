### 2.4 "参照范围"行 — 用户裁决组件，契约如下

**数据来源**：`analytics/baseline.py::compute_baseline(conn, metric_name, end_day, window_days=28, min_samples=14, mad_factor=2.5)`（只读，不改口径；参数即待确认项 U5）。

**呈现规则**（写在组件契约里，实现时逐条可测）：

| 基线状态 | 指标卡显示 | 说明 |
|---|---|---|
| `active` | `参照 个人基线 46–72 次/分`（中位数 ± 2.5×MAD，按基线实际值动态生成） | 数值由基线算出，**禁止写死任何静态区间** |
| `insufficient`（样本不足） | `参照范围 数据不足：近 28 天仅 8/14 天有效` | 用 `Baseline.reason` 原文，不得拿默认值冒充个性化（ERR-015） |
| `insufficient`（离散度为 0） | `参照范围 数据不足：近 28 天记录完全相同` | 同上 |
| `no_data` | `参照范围 暂无数据` | —— |
| `range_bound` 指标（HRV/血氧端点，共 4 个） | **不显示参照范围行** | 区间端点无基线概念（ERR-016） |

**文案铁律**：
- 只称"个人基线"，不出现"正常范围/健康范围/推荐值"；
- 必须带窗口与样本量（`近 28 天中位数，有效 20/28 天`），可放入 `<details>` 展开，不占主视觉；
- 当日值偏离基线时：中性文字标记 `偏离基线`（`--text-2`），**不用红/绿/琥珀着色**——避免"健康红绿灯"（是否允许琥珀色，见待裁决 D-3）；
- 与"睡眠目标"严格区分：**目标** = 配置值（`describe_sleep_target()` 已带来源标注），**参照范围** = 个人历史基线。两行可同卡并存，标签不同。

**心律失常类指标**（非数值）：不显示参照范围行，记录页原样展示设备文本。

### 3.2 选型结论

- **复制代码 0 个，新增依赖 0 个，新增构建步骤 0 个。**
- 采纳的"组件"全部是我们自己的 Jinja 宏 + CSS（§5 拟修改文件），Galaxy 只提供结构/视觉模式参考。
- 采用后置门槛（T04/T05 执行时逐条过）：① 纯 CSS 无 JS；② 非 Tailwind 版；③ 键盘可达 + focus-visible；④ 44px 触控；⑤ reduced-motion 友好；⑥ 浅色集对比度达标；⑦ 在 `docs/UI-ATTRIBUTION.md` 登记来源/创作者/修改。任不过关则自行实现。
- 理由记录：健康数据产品要求状态语义精确（三套语义 + 来源标注），通用组件反而要拆解重做；本项目零 JS 架构与多数星系组件（hover/自动消失/发光）天然冲突。

```
├ 明细表（最近 14 天：日期/时长/阶段/状态/来源）───────┤
└ 脚注：有效 5/7 天 · 缺失 2 天 · 不足 3 天不做趋势判断 ┘
```

- 阶段数据只存设备原值；只给比例不换算分钟，只给分钟不换算比例（既有约束）。
- 设备评分原值展示时标 `设备原值`。

### 4.4 历史趋势 `/trends`

```
标题：指标趋势
指标选择器（P0/P1 分组；provisional 指标带"暂定定义"虚线条）
范围：[7天][30天][90天]
┌ 参照范围行（本页主元素，常驻卡片顶部）────────────────┐
│ 静息心率 参照 个人基线 52–66 次/分（近28天 20/28 天）  │
│ ⇢ insufficient → "数据不足：有效记录 8/14 天，样本不足" │
│ ⇢ range_bound  → "该指标为区间端点，没有平均值，也不会   │
│                  被计算；不显示参照范围"               │
├ 主图（数值→折线 / 计数→柱 / range_bound→区间带）─────┤
├ 统计条：均值 中位 最小 最大 有效天数 缺失率 + status ─┤
└ 固定提示：仅统计已确认记录；周/月记录不参与日趋势 ─────┘
```

### 4.6 提醒与建议 `/alerts`

```
顶部：未读 N · [立即评估] · 筛选（全部/未读/按规则）
卡片：规则名徽标 + 窗口 + 触发原因 + 建议 + [依据 N 条记录 ⇢] + 三条反馈
```

- 严重度标签用规则名，不用"高/中/低"（设计规范 §3.7-D）。

### 4.7 设置与隐私 `/settings`

分区顺序：**外观 → 睡眠目标 → 生活背景 → 提醒阈值（只读）→ 数据与隐私 → 关于**

- 外观：模式切换（现有 `mode-switch`，`settings.html:10-15`）；Chronos 选项文案从"时钟模式（Demo）"更新为与 §4.2 实际能力一致（拖动旋转仍未实现就不写"旋转"）。
- 睡眠目标：只读 + 来源标注（`describe_sleep_target`）。
- 提醒阈值：只读表格 + 环境变量名；**不放可改的滑块**（假控件禁令）。
- 数据与隐私：导出 CSV/JSON、备份/恢复入口、"数据只在本机，AI 只发送已算好的摘要"声明。
- 删除数据说明：指向手动删库步骤，不做"一键删除"按钮（防误触）。
