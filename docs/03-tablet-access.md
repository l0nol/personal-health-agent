## 三、结论与建议

1. **可以试**：局域网 + 密码模式下，平板用浏览器访问在协议层面没有问题（表单、Cookie、CSRF 都按标准实现）。
2. **先做这三件事再上平板**：
   - Windows 防火墙放行端口（`netsh advfirewall firewall add rule name="health-agent" dir=in action=allow protocol=TCP localport=8000`）
   - 固定电脑的局域网 IP，或在路由器里做 DHCP 保留，否则重启后地址会变
   - 用 `passwd` 设密码——**没有密码程序拒绝启动局域网模式**
3. **预期会痛的三个点**（按可能性排序）：
   - 记录页表格在竖屏下需要横向滚动 → 建议后续把操作按钮收进"详情"折叠
   - 按钮触控区偏小 → 建议给 `.mini` 在 `max-width:640px` 下加 `min-height:32px`
   - 无 HTTPS 的安全提示 → 家庭网络可接受，公共网络不要用
4. **不建议做的事**：把服务暴露到公网、做端口转发、用免费内网穿透工具。当前鉴权只有单密码 + 无 HTTPS，
   不足以承受公网暴露。
