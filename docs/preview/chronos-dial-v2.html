交互说明（给 T11 的约束）

  • 拨到刻度：选中某个刻度只更新中心预览，不直接跳页；点「进入」才导航。与现有表盘"两步交互"一致。
  • 点中心：打开助手面板；助手是 T12 的范围，当前只做入口与输入框，不接模型。
  • 零 JS 等价物：本预览用单选控件实现"点刻度 → 换预览"，键盘 Tab/方向键可操作；拖拽旋转需要 JS。
  • 拖拽的代价：会打破项目"零 JS"约束，需单独提交理由、可访问性影响与降级方案，等用户批准后再做（T11 门禁）。
  • 不做的事：表盘颜色/角度不代表健康评分；不显示虚假总分；动画尊重 prefers-reduced-motion。
