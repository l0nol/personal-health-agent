## 三、结论与建议

1. **可以试**：局域网 + 密码模式下，平板用浏览器访问在协议层面没有问题（表单、Cookie、CSRF 都按标准实现）。
2. **先做这三件事再上平板**：
   - Windows 防火墙放行端口（`netsh advfirewall firewall add rule name="health-agent" dir=in action=allow protocol=TCP localport=8000`）
   - 固定电脑的局域网 IP，或在路由器里做 DHCP 保留，否则重启后地址会变
   - 用 `passwd` 设密码——**没有密码程序拒绝启动局域网模式**
3. **预期会痛的三个点**（按可能性排序）：
   - 记录页表格在竖屏下需要横向滚动 → 建议后续把操作按钮收进"详情"折叠
   - 按钮触控区偏小 → 建议给 `.mini` 在 `max-width:640px` 下加 `min-height:32px`
   - 无 HTTPS 的安全提示 → 家庭网络可接受，公共网络不要用
4. **不建议做的事**：把服务暴露到公网、做端口转发、用免费内网穿透工具。当前鉴权只有单密码 + 无 HTTPS，
   不足以承受公网暴露。

## 五、联想 Yoga Pad Pro 12.7（元启版）+ 联想浏览器（2026-10-20 追加）

> 设备与浏览器由用户提供，**尚未实测**。以下为针对性设置与验证步骤，
> 跑完后把结果填进 §5.4 的记录表，未实测前不得标记为"已验证"。

### 5.1 为什么单独写这一节

12.7 英寸平板有两个特点会影响布局：

1. **横屏宽度约 1400+ CSS px** → 会命中桌面布局（≥1280 侧栏 + 4 列指标卡）；
   竖屏约 900+ → 命中平板布局（顶部导航、表格转卡片）。
   两套布局都要看一眼，不能只看横屏。
2. **联想浏览器是定制内核**：多数版本基于 Chromium，但部分机型走系统 WebView，
   内核可能落后。本项目用到 `aspect-ratio`、`:focus-visible`、`clamp()`、CSS 自定义属性，
   **建议 Chromium ≥ 88**；已为 `aspect-ratio` 加了老内核兜底（`@supports not`），
   但更老的 `flex gap`（<84）不再兜底。

### 5.2 先做三项设置

| 设置 | 为什么 |
|---|---|
| 关闭"无图模式 / 极速模式 / 省流" | 这类模式可能屏蔽 CSS 或改字体，界面会错乱 |
| 页面缩放设为 100%（不要记忆缩放） | 缩放会让 `≥1280` 断点误判，表盘与侧栏比例失真 |
| 系统字体大小设为默认 | Android 字体放大会把指标卡文字挤出卡片（样式里已锁 `text-size-adjust`，但系统级放大仍可能生效） |

### 5.3 三步确认环境

1. **看内核版本**：联想浏览器 → 设置 → 关于，记录"内核版本 / Chromium xx"。
   若 < 88，直接换 Chrome 或更新系统 WebView 后再测。
2. **确认同一 Wi-Fi**：电脑上 `ipconfig` 找到 IPv4（如 `192.168.1.23`），
   平板浏览器打开 `http://<该IP>:8000/healthz`，应返回 `{"status":"ok"}`。
3. **密码与局域网**：电脑 `.env` 里必须有 `HEALTH_AGENT_LAN=1` 和
   `HEALTH_AGENT_PASSWORD_HASH=...`（`cli passwd` 生成），否则局域网访问会被拒。

### 5.5 平板专属的已知风险（未实测前按此预期）

- **联想浏览器的"网页翻译/阅读模式"** 可能改写 DOM，导致提示条重复；遇到请在地址栏关掉。
- 12.7 英寸高分屏下 1px 边框可能显示为很细的灰线，属正常（未做 2x 图适配）。
- 平板横屏时 `.chronos` 两栏并排、表盘直径受 `clamp(104px, 28vw, 148px)` 限制为 148px 半径，
  视觉上偏小但触控够用；如觉得小，改 `tokens.css` 里的 `--dial-r` 上限即可。
